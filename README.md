# City Delivery Rush

City Delivery Rush is a 3D delivery simulation game developed in Unity using C#.

The player navigates through a city, enters and exits vehicles, completes randomized delivery missions, earns rewards, and interacts with a dynamic environment containing traffic and pedestrians.

## Features

- Randomized pickup and drop-off locations
- Vehicle enter and exit system
- Player movement system
- GTA-style delivery markers
- Timed delivery missions
- Money and reward system
- Pedestrian spawning system
- Traffic vehicle system
- Camera follow system
- Main menu
- Continuous delivery gameplay loop

## Technologies Used

- Unity
- C#
- Unity Physics
- NavMesh / AI systems
- Git
- GitHub

## Gameplay

Players receive delivery objectives at randomly selected locations around the city.

After reaching the pickup location, the player collects the delivery and transports it to the assigned drop-off location before the timer expires.

Successful deliveries reward the player with in-game money and generate a new delivery mission.

## Controls

### On Foot

- `WASD` / Arrow Keys — Move
- `E` — Enter Vehicle
- `F` — Exit Vehicle

### Vehicle

- `WASD` / Arrow Keys — Drive
- `F` — Exit Vehicle
